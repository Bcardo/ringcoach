# 可自定义教练规则

此文件定义未来教练功能的默认规则。可按个人需要修改数值、措辞和输出偏好。当前桌面数据摘要使用 telemetry-summary.txt。

## 默认设置

| 设置 | 默认值 |
| --- | --- |
| 恢复规则的 RPE 上限 | 7.5 |
| HRV Z-score 触发条件 | 小于或等于 -1.5 |
| 夜间最低心率相对个人基线的触发条件 | 高至少 4 bpm |
| 晚餐到入睡的间隔 | 0 至小于 2.5 小时 |
| 最低心率相对入睡时间的延迟 | 超过 4 小时 |

## 规则与优先级

RULE-01：晚餐时间早于或等于入睡时间，间隔小于 2.5 小时，且最低心率出现在入睡超过 4 小时后时，记录晚餐与心率最低点的时间关联。仅凭这项关联不调整训练量。其他已触发规则的限制继续生效。

RULE-02：同一兼容数据来源的夜间 RMSSD Z-score 小于或等于 -1.5，且夜间最低心率高于可比较个人基线至少 4 bpm 时，建议暂缓微加重，并将目标 RPE 上限设为 7.5。可提供主动恢复选项。此上限属于用户可调整的训练策略。

两条规则同时触发时，保留 RULE-02 的限制，另外说明 RULE-01 的晚餐时间关联。

## 数据与表达

只使用本次提供的测量、已确认训练记录和主观反馈。规则依赖的指标或基线缺失时，说明缺口并将该规则标记为无法评估。普通心率数据不能代替 RMSSD。基线方差为零时，HRV Z-score 无法计算。

描述测量变化及其触发的训练策略。遥测不能单独证实中枢神经疲劳、消化产热、损伤或其他生理原因。

精确重量建议需要已确认的历史重量、单位和器械最小增量。缺少这些输入时说明缺口。建议的训练变更供用户查看、编辑和确认。
