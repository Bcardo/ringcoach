Download Samsung Health Data SDK 1.1.0 from https://developer.samsung.com/health/data/process.html and place `samsung-health-data-api-1.1.0.aar` here. The SDK binary is intentionally ignored by Git; use your own Samsung-authorized download.

The build applies Kotlin Parcelize and includes Gson, both required by the SDK runtime. The development APK uses Samsung Health's SDK developer read mode and the owner's Energy Score read grant. Distribution requires Samsung's partner registration.
